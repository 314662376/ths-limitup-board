# 涨停 / 炸板 情绪看板（883900 / 883918）

纯静态页面，浏览器直连同花顺公开行情接口，实时展示两个短线情绪指数。无后端、无构建、无依赖服务。

| 代码 | 名称 | 含义 |
|---|---|---|
| `883900` | 昨日涨停表现 | 上一交易日**收盘涨停**的个股在本交易日的整体表现（等权），衡量「打板赚钱效应」 |
| `883918` | 昨日炸板股 | 上一交易日**曾涨停但收盘未封住**的个股在本交易日的整体表现，衡量「炸板亏钱效应」 |

> 两者互为对照：883900 上涨、883918 下跌，通常意味着打板资金赚钱、炸板资金亏钱，短线情绪偏暖；反之则情绪转弱。

---

## 数据来源

同花顺公开行情接口 `d.10jqka.com.cn`，返回 JSONP，响应头带 `Access-Control-Allow-Origin: *`，可被任意站点跨域调用（无需代理、无需密钥）。

| 用途 | 接口 | 回调名 |
|---|---|---|
| 实时快照 | `https://d.10jqka.com.cn/v2/realhead/48_{code}/last.js` | `quotebridge_v2_realhead_48_{code}_last` |
| 日K数据 | `https://d.10jqka.com.cn/v6/line/48_{code}/01/last.js` | `quotebridge_v6_line_48_{code}_01_last` |
| 当日分时 | `https://d.10jqka.com.cn/v6/time/48_{code}/last.js` | `quotebridge_v6_time_48_{code}_last` |

其中 `{code}` 为 `883900` 或 `883918`，路径前缀固定为 `48_`。

### 实时快照字段（`items` 对象，键为数字字符串）

| 键 | 含义 |
|---|---|
| `10` | 最新价 |
| `6` | 昨收 |
| `7` / `8` / `9` | 今开 / 最高 / 最低 |
| `13` / `19` | 成交量 / 成交额 |
| `199112` | 涨跌幅（%） |
| `264648` | 涨跌额 |
| `1968584` | 换手率（%） |
| `526792` | 量比 |

### 两个已踩过的坑

1. **浏览器跨域请求只返回 `items`**，`name` / `updateTime` 等顶层字段在服务端 curl 直连时才有。因此页面里的行情日期改从分时接口的 `date` 字段取。
2. **并发请求会被限流**（同一 IP 同时发 6 个请求时会出现部分失败）。页面已改为「按指数串行 + 单请求失败重试一次 + 指数间隔 350ms」，部分失败时也会展示已拿到的数据。
3. 接口响应带 `Cache-Control: max-age=60`，所以页面自动刷新间隔设为 **60 秒**。

## 本地运行

```bash
# 任意静态服务器均可
python -m http.server 8899
# 然后打开 http://127.0.0.1:8899/
```

> 直接双击 `index.html` 用 `file://` 打开通常也能工作，但用本地 HTTP 服务更稳定。

## 文件结构

```
index.html          页面结构 + 样式
app.js              JSONP 取数、字段映射、图表渲染、自动刷新
lib/echarts.min.js  ECharts 5.4.3（本地内置，不依赖 CDN）
```

git push -u origin main

然后在仓库 **Settings → Pages** 中把 Source 设为 `main` 分支根目录，首次构建约 1 分钟，访问
`https://<用户名>.github.io/<仓库名>/`。
